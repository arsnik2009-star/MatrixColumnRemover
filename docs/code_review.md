# Инспекция интеграционного кода

Проверены границы модулей, имена сущностей, обработка исключений, отсутствие дублирования и соответствие PEP 8.

Исправления и принятые решения:

- денежные значения представлены типом `Decimal`;
- REST API не возвращает клиенту трассировку Python;
- ошибки преобразуются в стабильные JSON-коды;
- внешний контракт отделён от внутреннего хранения;
- модуль транзакций возвращает средства отправителю при сбое пополнения получателя;
- `flake8` запускается локально и в GitHub Actions.
