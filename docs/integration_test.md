# Тестирование интеграции

Проверены следующие сценарии:

1. Вызов верхнего уровня с заглушками нижних модулей.
2. Создание двух счетов и перевод между ними.
3. Запись перевода в историю обоих счетов.
4. Пополнение и снятие средств.
5. Отказ при недостатке средств.
6. Отказ при переводе на тот же счёт.
7. Недоступность обязательного модуля.
8. Таймаут ответа модуля.
9. Конфликт версии JSON-контракта.
10. Проверка HTTP-кодов 200, 201, 404, 409, 422, 503 и 504.

Интеграционные тесты запускаются командой `pytest -v`. Покрытие проверяется командой `coverage report --fail-under=90`.
