# Архитектура проекта

Модуль `matrix_column_remover.py` разделён на ввод данных, проверку матрицы, удаление столбца и вывод результата. Функция `remove_column` не выполняет ввод и вывод, поэтому её можно независимо тестировать и использовать из других модулей.

Поток данных: пользовательский ввод -> проверка -> удаление столбца -> форматированный вывод.
