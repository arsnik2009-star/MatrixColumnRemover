# Архитектура проекта MatrixColumnRemover

## Компоненты
- `src/matrix_column_remover.py` — модуль удаления столбца.
  - Функция `remove_column(matrix, k)` — чистая функция, выполняет удаление.
  - Функция `main()` — интерфейс пользователя (ввод/вывод).
- `tests/test_matrix.py` — модульные тесты.

## Взаимодействие
Пользователь вводит размеры матрицы и саму матрицу, затем номер столбца.
`main()` вызывает `remove_column()`, которая возвращает новую матрицу.
Результат выводится на экран.
