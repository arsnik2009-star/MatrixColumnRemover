# Ревью матричной программы

Проверены разделение вычислений и пользовательского ввода, обработка некорректного номера столбца, прямоугольность матрицы, понятность имён и соответствие PEP 8.

После исправлений вычислительная функция не имеет побочных эффектов, ошибки передаются через `ValueError`, а запуск программы защищён условием `if __name__ == "__main__"`.
