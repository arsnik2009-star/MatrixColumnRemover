# Обзор российских аналогов Git

| Продукт | Назначение | Возможности | Преимущества | Ограничения |
|---------|------------|-------------|--------------|-------------|
| GitFlic | DevOps-платформа | Git, CI/CD, Issues, PR | В реестре РФ, облако/локально | Меньше плагинов |
| GitFlame | Хранение репозиториев | Git, совместная работа | Простой интерфейс | Меньше интеграций |
| Gitlife Enterprise | Управление жизненным циклом | Модуль «Код» на Git | Корпоративный сектор | Сложность внедрения |
| Deckhouse Code | CI/CD и хранение кода | Git, CI/CD | Российский реестр | Зависимость от Deckhouse |
| EvaGit | Управление Git-репозиториями | Ветки, коммиты, PR, code review | В составе EvaTeam | Экосистема EvaTeam |
| Mos.Hub | Городской репозиторий | Git, open source | Бесплатный для города | Городской проект |
