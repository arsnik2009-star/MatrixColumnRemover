Стратегия ветвления

В проекте используется упрощённый **GitHub Flow**.

Ветки
- `master` — стабильная версия, всегда рабочая.
- `develop` — ветка текущей разработки.
- `conflict-branch` (и другие временные) — для отдельных задач.

Процесс
1. Новая задача → отдельная ветка от `master` или `develop`.
2. Коммиты в этой ветке.
3. Слияние в `develop` (или напрямую в `master` для мелких правок).
4. После проверки — слияние `develop` в `master`.

Обоснование выбора
GitHub Flow прост в освоении и оптимален для небольших учебных проектов:
- нет долгоживущих веток, кроме master и develop;
- каждая задача решается в отдельной короткоживущей ветке;
- основная ветка всегда содержит рабочую версию;
- легко проследить историю через `git log --graph`.

Краткое назначение
Программа предназначена для обработки вещественных матриц в учебных и демонстрационных целях. Она позволяет удалить столбец с заданным номером k из матрицы размерности n × m. Область применения — лабораторные работы по программированию, курсы по алгоритмам и структурам данных.

Требования к окружению:
- Операционная система: Windows, Linux или macOS.
- Python версии 3.8 и выше.
- Сторонние библиотеки не требуются (используются только стандартные модули Python).
- Процессор с тактовой частотой не менее 1 ГГц, ОЗУ не менее 512 МБ.
