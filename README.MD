Краткое назначение
Программа предназначена для обработки вещественных матриц в учебных и демонстрационных целях. Она позволяет удалить столбец с заданным номером k из матрицы размерности n × m. Область применения — лабораторные работы по программированию, курсы по алгоритмам и структурам данных.

Требования к окружению:
- Операционная система: Windows, Linux или macOS.
- Python версии 3.8 и выше.
- Сторонние библиотеки не требуются (используются только стандартные модули Python).
- Процессор с тактовой частотой не менее 1 ГГц, ОЗУ не менее 512 МБ.

Инструкция по запуску (предварительная):
1. Откройте терминал (Git Bash в Windows) и перейдите в каталог проекта.
2. Запустите программу командой:
   ```bash
   python src/matrix_column_remover.py
