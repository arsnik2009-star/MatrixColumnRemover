# Лабораторные работы по разработке программного обеспечения

Учебный проект для лабораторных работ по дисциплине «Инструментальные средства разработки программного обеспечения».

В ЛР №1 и ЛР №2 реализована программа удаления выбранного столбца вещественной матрицы. В ЛР №3 добавлена упрощённая банковская система варианта 13: создание и обслуживание счетов, переводы между счетами и формирование истории операций.

Автор: Николаев Арсений Александрович, группа Т9-ИП-25-3, вариант 13.

## Требования

- Python 3.9 или новее;
- Windows или GNU/Linux.

## Структура ЛР №3

- `account_service.py` - создание счёта, пополнение и снятие;
- `transaction_service.py` - перевод между счетами;
- `report_service.py` - история операций;
- `integration.py` - координация модулей и контроль таймаутов;
- `api.py` - REST API с сообщениями JSON.

Использована нисходящая интеграция. Сначала REST API проверяется с заглушками нижних модулей, затем заглушки заменяются рабочими сервисами.

## Запуск матричной программы

```bash
python src/matrix_column_remover.py
```

## Запуск REST API

```bash
python -m pip install -r requirements.txt
python src/server.py
```

Документация OpenAPI будет доступна по адресу `http://127.0.0.1:8000/docs`.

## Проверка

```bash
python -m pytest -v
coverage run -m pytest
coverage report --fail-under=90
flake8 src tests
```

## Ветвление

Основная стабильная ветка - `main`. Изменения разрабатываются в короткоживущих тематических ветках и добавляются в `main` через Pull Request после автоматической проверки.
