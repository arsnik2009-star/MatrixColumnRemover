# Удаление столбца матрицы

Учебный проект для лабораторных работ по дисциплине «Инструментальные средства разработки программного обеспечения».

Программа вводит вещественную матрицу размером `n x m`, удаляет столбец с заданным номером `k` и выводит исходную и результирующую матрицы.

Автор: Николаев Арсений Александрович, группа Т9-ИП-25-3, вариант 13.

## Требования

- Python 3.9 или новее;
- Windows или GNU/Linux.

## Запуск

```bash
python src/matrix_column_remover.py
```

## Проверка

```bash
python -m pytest -v
flake8 src tests
```

## Ветвление

Основная стабильная ветка - `main`. Изменения разрабатываются в короткоживущих тематических ветках и добавляются в `main` через Pull Request после автоматической проверки.
